# Jewelry CAD Optimizer (Elite Submission)

Веб-приложение для автоматической реставрации, очистки от шума и подготовки к 3D-печати ювелирных сканов. 

## Особенности (Features)
- **MCP (Mesh Context Protocol)**: Интеллектуальный анализ геометрии.
- **Auto-Layering**: Разделение камней и металлической оправы на основе графа связности.
- **Noise Heatmap**: Визуализация удаленного сканирующего шума через Vertex Colors.
- **Cost Estimator**: Калькулятор стоимости изделия в реальном времени.
- **Batch Processing Ready**: Архитектура, поддерживающая параллельную загрузку и очистку нескольких моделей.

## Как мы реализовали алгоритмы

### MCP (Mesh Context Protocol)
Для динамического подбора параметров фильтрации мы написали анализатор (`core/mcp_analyzer.py`), который на лету сэмплирует нормали вершин исходного меша (до 10 000 полигонов) и вычисляет их дисперсию (`np.var(normals)`). Чем выше дисперсия — тем больше шума (артефактов сканера) на поверхности. В зависимости от этого параметра алгоритм автоматически подбирает количество итераций сглаживания и порог децимации.

### Auto-Layering (Stone Separation)
Частая проблема 3D-сканирования ювелирных изделий — вставки (камни) не привязаны к металлической оправе топологически (находятся в "воздухе" внутри крапанов). 
В `core/separators.py` мы используем анализ графа связности компонентов (`trimesh.graph.connected_components`). 
**Логика:** алгоритм вычисляет объем (или convex hull для незакрытых участков) каждого несвязанного компонента. Все компоненты, объем которых составляет менее 15% от самого большого, автоматически классифицируются как камни, отделяются от основного меша в самостоятельные слои и не подвергаются сглаживанию.

## Стек технологий
- **Backend:** Python, FastAPI, PyMeshLab (C++ Geometry engine), Trimesh, Open3D, Numpy.
- **Frontend:** React, Vite, Tailwind CSS, Zustand, @react-three/fiber (Three.js), Lucide React.

## Инструкция по запуску

### 1. Запуск Backend (API & Geometry Engine)
1. Перейдите в папку бекенда: 
   ```bash
   cd backend
   ```
2. (Опционально) Создайте виртуальное окружение: 
   ```bash
   python -m venv venv && source venv/bin/activate
   ```
   *Для Windows:* `venv\Scripts\activate`
3. Установите зависимости: 
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите сервер: 
   ```bash
   uvicorn main:app --reload
   ```
   Сервер будет доступен по адресу `http://localhost:8000`. Встроенная документация Swagger: `http://localhost:8000/docs`.

### 2. Запуск Frontend (UI)
1. Перейдите в папку фронтенда: 
   ```bash
   cd frontend
   ```
2. Установите зависимости: 
   ```bash
   npm install
   ```
   *(Убедитесь, что установлены `three`, `@react-three/fiber`, `@react-three/drei`, `zustand`, `lucide-react`, `tailwindcss`)*
3. Запустите Dev-сервер: 
   ```bash
   npm run dev
   ```
   Интерфейс будет доступен по адресу `http://localhost:5173`.
