# 💎 Jewelry CAD Optimizer — Документация функций

Это полный список всех функциональных возможностей платформы Jewelry CAD Optimizer.

## 📥 1. Загрузка и управление файлами
- **Drag & Drop интерфейс:** Поддержка интуитивного перетаскивания файлов прямо в окно браузера.
- **Поддержка профессиональных форматов:** Обработка файлов `.stl`, `.obj` и `.ply`, которые являются стандартом в 3D-сканировании ювелирных изделий.
- **Индикация процесса:** Визуальное отображение статуса обработки (загрузка, процесс очистки геометрии, готовый результат) с анимациями.

## 🛠️ 2. Геометрический Backend-движок (PyMeshLab + Trimesh)
- **Удаление шума сканирования:** Автоматическое применение алгоритмов сглаживания (Taubin smoothing) через интеграцию с PyMeshLab для устранения артефактов поверхностного шума без потери мелких деталей (например, крапанов).
- **Разделение компонентов (Сегментация):** Умный алгоритм, который разделяет цельную сетку на основной металлический каркас и отдельные элементы (драгоценные камни).
- **Умная децимация (LOD):** Автоматическое снижение количества полигонов (Quadric Edge Collapse) для оптимизации и быстрой работы в браузере при сохранении визуального качества.
- **Заполнение дыр (Hole Filling):** Восстановление нарушенной топологии (watertight mesh), чтобы объём изделия рассчитывался корректно.

## 📏 3. Интеллектуальный анализ геометрии
- **Автоматическое определение размера кольца:** Инструмент делает "срез" геометрии (cross-section) по наименьшей оси, находит внутреннее отверстие и автоматически высчитывает размер кольца в миллиметрах.
- **Габариты (Bounding Box):** Расчет максимальных габаритов изделия по осям X, Y, Z.
- **Расчет объема и площади:** Точный математический расчет объема (мм³) и площади поверхности (мм²) для вычисления веса изделия в металле.

## 🎨 4. Интерактивный 3D-Вьюер (React Three Fiber)
- **Двойной рендеринг (Dual Rendering):** Одновременная загрузка "сырой" (исходной) и "чистой" (оптимизированной) 3D-моделей.
- **Плавное сравнение (Cross-fade Slider):** Ползунок, позволяющий в реальном времени плавно изменять прозрачность слоев, чтобы сравнить результат "До" и "После".
- **Интерактивная камера:** Управление камерой с помощью мыши (вращение, зум, панорамирование) и возможность включить **Автоматическое вращение** для демонстрации.
- **Отображение топологии:** Кнопка для включения режима Wireframe (сетки), чтобы оценить качество геометрии и полигонов после оптимизации.
- **Обработка ошибок (ErrorBoundary):** Встроенная защита от падений WebGL — если загружена поврежденная модель, система выдаст понятную визуальную ошибку, а не пустой экран.

## 💰 5. Калькулятор материалов и стоимости
- **PBR-рендеринг материалов:** Физически корректное отображение различных металлов (Золото 14K, Золото 18K, Серебро 925, Платина) с учетом их реальной шероховатости (roughness) и металличности (metalness).
- **Автоматический пересчет веса:** Перемножение объема модели на плотность выбранного сплава для получения реального веса готового ювелирного изделия.
- **Оценка стоимости:** Расчет примерной стоимости металла (без учета камней и работы) на основе актуальной цены за грамм для выбранного материала.

## 🌡️ 6. Анализ отклонений (Heatmap Shader)
- **Визуализация изменений:** Специально написанный кастомный GLSL шейдер, который окрашивает участки модели в зависимости от того, насколько сильно они изменились после сглаживания.
- **Градиент температур:** 
  - Синий цвет: Участок геометрии остался неизменным.
  - Зеленый цвет: Среднее изменение (сглажен небольшой шум).
  - Красный цвет: Сильное изменение (исправлен крупный дефект или дыра).
- **Регулировка интенсивности:** Отдельный ползунок для настройки яркости тепловой карты без влияния на физическую форму объекта.
