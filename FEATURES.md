# 💎 Документация архитектуры и функционала: Jewelry CAD Optimizer

**Jewelry CAD Optimizer** — это комплексная программная платформа, состоящая из высокопроизводительного серверного движка (FastAPI + Python) и интерактивного клиентского приложения (React + Three.js). Инструмент предназначен для профессиональной ювелирной отрасли: он автоматизирует процесс восстановления "сырых" 3D-сканов, анализирует геометрию и предоставляет инструменты для визуального и финансового контроля.

Ниже представлено максимально детальное техническое описание всех подсистем и функций проекта.

---

## 1. ⚙️ Интеллектуальный процессинг 3D-геометрии (Бэкенд)
Серверная часть построена на связке библиотек **PyMeshLab** и **Trimesh**, обеспечивая математически точную обработку полигональных сеток.

*   **Удаление поверхностного шума (Taubin Smoothing):** Применяется алгоритм сглаживания Таубина без усадки (non-shrinking smoothing). Он эффективно устраняет высокочастотные артефакты сканирования, строго сохраняя габариты изделия и критически важные мелкие детали, такие как крапаны для закрепки камней и гравировки.
*   **Автоматическая топологическая сегментация:** Система анализирует связность компонентов (mesh splitting). Она способна отличить основную металлическую основу изделия от изолированных элементов (например, драгоценных камней), чтобы обрабатывать металл отдельно и сохранять грани камней острыми.
*   **Восстановление целостности (Hole Filling):** Алгоритм автоматически находит и закрывает не-манифолдные (non-manifold) отверстия в сетке, делая модель "водонепроницаемой" (watertight). Это обязательное условие для корректного расчета объема.
*   **Умная децимация (LOD Generation):** Используется метод *Quadric Edge Collapse*, который автоматически оптимизирует высокополигональную сетку (сводит количество полигонов к оптимуму < 100 000 граней). Это гарантирует стабильно высокий FPS при рендеринге в браузере без визуальной потери качества.
*   **Вычисление отклонений (Vertex Distance Mapping):** Система измеряет евклидово расстояние между вершинами оригинального "шумного" скана и оптимизированной модели. Эти данные "зашиваются" в Vertex Colors (вершинные цвета) для последующего рендеринга тепловой карты.

---

## 2. 📐 Продвинутая геометрическая аналитика (Метрология)
Система проводит точные измерения виртуального объекта для подготовки к производству.

*   **Алгоритмическое определение размера кольца:** Ядро вычисляет минимальную ось объекта и делает математический срез (cross-section). Затем анализируется внутренний контур крупнейшего полигона среза для автоматического вычисления точного внутреннего диаметра кольца (в миллиметрах).
*   **Оценка габаритов (Bounding Box):** Точный расчет максимальных координат X, Y и Z (длина, ширина, высота) в глобальном пространстве, что необходимо для планирования 3D-печати.
*   **Вычисление физических метрик:** Интегрированный расчет общего объема модели (в мм³) и суммарной площади поверхности (в мм²), учитывая сложную геометрию и внутренние полости.

---

## 3. 🎨 Интерактивный 3D WebGL Вьюер (Фронтенд)
Пользовательский интерфейс использует **React Three Fiber (Three.js)** для аппаратного ускорения графики в браузере.

*   **Двойной рендеринг (Dual-Mesh Overlay):** Система загружает одновременно две версии модели (исходную и обработанную).
*   **Слайдер бесшовного сравнения (Cross-fade slider):** Механизм, динамически связывающий прозрачность (opacity) двух наложенных моделей. Пользователь может плавно переключаться между "До" и "После", детально оценивая внесенные алгоритмом изменения.
*   **PBR (Physically Based Rendering) Шейдеры:** Использование передовых шейдеров `MeshStandardMaterial` для реалистичной имитации металлов. Настроены точные коэффициенты шероховатости (roughness), металличности (metalness) и RGB-значения для симуляции:
    *   Золота 14K и 18K
    *   Серебра 925 пробы
    *   Платины
*   **Отказоустойчивость WebGL (Error Boundaries):** Многоуровневая защита от падений (Crashes). В случае поврежденного файла или потери контекста видеокарты, приложение изолирует ошибку внутри компонента и предлагает перезагрузку вместо зависания интерфейса (white screen of death).

---

## 4. 🌡️ Визуализация деформаций (Heatmap GLSL Shader)
Специально разработанный кастомный шейдер для технического контроля.

*   **Программный Fragment Shader:** Программа, выполняющаяся на GPU, читает отклонения вершин, записанные бэкендом в канал Red.
*   **Цветовое кодирование:** На основе полученных значений формируется тепловой градиент (`mix(blue, green, red)`):
    *   **Синий:** 0% отклонения (идеальное совпадение поверхностей).
    *   **Зеленый:** Минимальные корректировки.
    *   **Красный:** Максимальная деформация (места, где находились крупнейшие артефакты сканирования).
*   **Динамическая интенсивность:** Слайдер `heatmapIntensity` позволяет пользователю плавно "вмешивать" тепловую карту поверх PBR-материала металла, не теряя восприятия объема изделия.

---

## 5. 💰 Калькулятор технологического процесса
Интеграция геометрических данных с бизнес-логикой (State Management via Zustand).

*   **Оценка веса в металле:** Умножение рассчитанного объема модели на физическую плотность выбранного драгоценного сплава (г/см³). Результат мгновенно пересчитывается при выборе другого металла в интерфейсе.
*   **Финансовая оценка (Estimator):** Предварительный расчет стоимости сырья на основе текущей рыночной цены за грамм металла, что позволяет мастеру моментально получить базовую себестоимость изделия.

---

## 6. 🌐 REST API и архитектура потоков данных
*   **Асинхронная пакетная обработка (Background Tasks):** При загрузке тяжелых файлов сервер моментально возвращает `job_id`, передавая тяжелые геометрические вычисления в фоновый процесс, чтобы не блокировать работу API.
*   **Smart Polling:** Фронтенд аккуратно опрашивает сервер о статусе готовности каждые 2 секунды, обеспечивая бесшовный пользовательский опыт с прогресс-барами.
*   **Мульти-форматная поддержка:** API валидирует и корректно разбирает форматы `.stl`, `.obj` и `.ply`, возвращая оптимизированный `.glb` с зашитыми бинарными данными для фронтенда.
